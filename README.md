# DataProject - SQL Exercises
![image](https://github.com/user-attachments/assets/cb87f180-13d0-46ff-878f-669187d955b0)

## Descripción

Este repositorio contiene una serie de ejercicios de SQL diseñados para practicar consultas y manipulación de datos en una base de datos relacional. Incluye la creación del esquema de la base de datos y consultas que abarcan diferentes operaciones como filtrado, agregación, uniones y funciones estadísticas.

## Contenido del Repositorio

esquemaBBDD.png: Imagen con el esquema de la base de datos utilizada en los ejercicios.

exercices.sql: Archivo con los ejercicios de SQL.

## Instrucciones de Uso

**1. Clonar el repositorio:**
git clone https://github.com/tu_usuario/DataProject-SQL-Exercises.git

**2. Crear la Base de Datos:** Crea una nueva base de datos en tu gestor SQL.

**3. Importar el Esquema:** Usa el archivo esquemaBBDD.png como guía para crear las tablas y relaciones en tu base de datos.
  
**4. Ejecutar los Ejercicios:** Copia y ejecuta las consultas del archivo exercices.sql en tu cliente SQL.
